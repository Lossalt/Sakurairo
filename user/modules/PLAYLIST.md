# 本地曲库 playlist.json 说明

可选。放在**音乐库根目录**，例如：

```text
/var/www/html/wp-content/bgm/playlist.json
```

## 作用

| 有无 playlist.json | 行为 |
|---|---|
| **没有** | 自动扫描曲库（含子目录）里的音频，按路径排序 |
| **有** | **只**播列表里的曲目，按文件里的顺序 |

## 格式

JSON **数组**，每个元素二选一：

1. **字符串**：音频相对路径  
2. **对象**：可指定显示名、歌手  

```json
[
  "Aimer - my sweetest one.flac",
  "sub/余静 - 正青春.mp3",
  {
    "file": "live/encore.mp3",
    "name": "安可",
    "artist": "某歌手"
  }
]
```

| 字段 | 说明 |
|---|---|
| `file` | 必填（对象写法）。相对曲库根目录，**不要** `../` |
| `name` | 可选。播放器显示的曲名；不填则用标签/文件名 |
| `artist` | 可选。不填则用标签/文件名解析 |

路径请用 `/` 分隔；文件必须在曲库目录内且真实存在，否则会跳过。

## 和歌词、封面的关系

- 歌词：同名 `.lrc` → 内嵌标签 → 无  
- 封面：内嵌标签 → 同名图（jpg/jpeg/png/webp/gif）  

改完 `playlist.json` 后刷新页面即可，无需改主题设置。
